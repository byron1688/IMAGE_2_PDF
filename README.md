# IMAGE_2_PDF

一个把图片合并导出成 PDF 的桌面小工具（先在 macOS 上可运行）。

## 目标功能

- **导入照片**：一张一张导入，也支持**拖拽（drag & drop）**——鼠标把文件从文件夹拖进来的感觉。
- **调整顺序**：导入后可以拖动重新排序。
- **每张图片可编辑**：旋转、裁剪等基础操作。
- **预览**：导入后带缩略图 / 预览。
- **支持的图片格式**：JPG、PNG（后续可扩展）。
- **导出**：把当前顺序的图片合成一个 PDF，导出到指定文件夹。
- **平台**：macOS 可运行；后续支持 Android 手机。
- **构建 / 分发**：用 GitHub Actions 自动 build。

## 状态
